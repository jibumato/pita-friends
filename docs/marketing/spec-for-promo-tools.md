# ピタフレ 仕様サマリー（販促ツール用）

> **この文書の目的**
> Codex 等で販促ツール（料金シミュレーター・報酬計算機・LP・比較表など）を
> 作るための、**数値と規則の単一の出典**です。
>
> **⚠️ 値は推測せず、2026-09-13 時点の適用済みスキーマ（0121 まで）から
> 直接引いています。** 出典の関数名・テーブル名を各項に書いてあるので、
> 疑わしいときはそちらを見てください。
>
> **⚠️ 運営コンソールから変えられる値があります**（料率・制限値）。
> 変更したら、この文書と `docs/marketing/sns-launch-kit.md` §6-2 を
> **必ず両方**直してください。告知の数字だけが古くなるのが、いちばん起きやすい事故です。

## 0. まず読むべき制約（販促コピーを生成させる前に）

販促ツールが文章を生成するなら、**§9 の禁止事項を必ずプロンプトに含めてください。**
ここを外すと、景品表示法・特定商取引法・出会い系サイト規制法に触れる文面が出ます。

とくに間違えやすい3点を先に書きます。

1. **「手数料最大10%」は事実と逆です。** 最大は 20%、10% は下限です
2. **「ホスト」「キャスト」と呼ばない。** アプリ内の呼称は **ピタメイト**
3. **確定していない特典を予告しない。** 購入時の上乗せコインは廃止済みで、
   現在「お得」と言える材料はありません

## 1. サービスの基本

| 項目 | 内容 |
|---|---|
| サービス名 | ピタフレ |
| 提供する役務 | **オンラインゲームの同行プレイ**（一緒に遊ぶ時間） |
| 役務の当事者 | ゲスト ⇄ ピタメイト（**運営は場の提供者**。役務提供契約は当事者間） |
| 呼称 | 遊びたい側＝**ゲスト** ／ 提供する側＝**ピタメイト** |
| 利用年齢 | **18歳以上**（未成年は利用不可） |
| 居住地 | **日本国内に居住している方のみ**（購入時に申告を確認） |
| 決済 | Stripe（クレジットカード・WeChat Pay・Alipay。いずれも料率 3.6%） |
| 3Dセキュア | EMV 3-D セキュア **必須**（外せない） |

**役務の範囲（恒久的な制約・広げられません）**

- オンラインゲームの同行プレイに限定
- **対面での同伴はしない**
- **顔出し中心のビデオ通話はしない**
- **接客業を想起させる呼称・演出をしない**

## 2. コインと購入

### 2-1. レート

**1コイン = 1円**（購入時・換金時とも。ボーナス倍率はありません）

### 2-2. 販売パック（`coin_packs`・active のみ）

| パックID | コイン | 価格 |
|---|---:|---:|
| `pack_500` | 500 | ¥500 |
| `pack_1000` | 1,000 | ¥1,000 |
| `pack_3000` | 3,000 | ¥3,000 |
| `pack_5000` | 5,000 | ¥5,000 |
| `pack_10000` | 10,000 | ¥10,000 |
| `pack_20000` | 20,000 | ¥20,000 |
| `pack_50000` | 50,000 | ¥50,000 |

| 表示 | **Stripe の明細で別行**。コイン代金と合算しない |
| 名目 | 本人確認・承認制・通報ブロック・トラブル時の対応にかかる費用 |

**計算例**

| パック | コイン代金 | サポート料 | 支払総額 |
|---|---:|---:|---:|

| ¥1,000 | ¥1,000 | ¥50 | **¥1,050** |

## 3. 料金（ゲストが払う額）

### 3-1. ピタメイトの料金設定

| 項目 | 値 |
|---|---|
| 設定単位 | **30分あたりのコイン**（画面表示）。内部は時給で保持 |
| 設定範囲 | 時給 **50〜2,000コイン**（＝30分あたり **25〜1,000コイン**） |
| 換算 | `30分料金 = round(時給 ÷ 2)`（`coinsPer30()`） |

### 3-2. 予約料金の計算

```
料金コイン = round(時給 × 分 ÷ 60)          … coinsForDuration()
請求コイン = max(1, round(料金コイン × (100 − 割引%) ÷ 100))
```

**計算例（時給1,000コイン＝30分500コイン）**

| 長さ | 料金 |
|---|---:|
| 30分 | 500 コイン |
| 60分 | 1,000 コイン |
| 90分 | 1,500 コイン |
| 120分 | 2,000 コイン |

### 3-3. 予約できる長さ（`is_valid_booking_duration()`）

| 範囲 | 刻み |
|---|---|
| 30分 〜 240分 | **30分刻み** |
| 240分 〜 600分 | **60分刻み** |

最長 **10時間（600分）**。

### 3-4. 初回お試し割引

- ピタメイトが **0〜90%** で設定（`trial_discount_percent`）
- **その人と初めて遊ぶゲストだけ**が割引価格で予約できる。2回目以降は通常価格
- **手数料は割引後の金額にかかる**（値引きした分だけ手数料も下がる）

### 3-5. 予約の受付範囲

| 項目 | 値 |
|---|---|
| 最短リードタイム | **30分後から**（`min_lead_minutes`） |
| 最長 | **35日先まで**（`max_lead_days`） |

## 4. ★ 報酬体系（ピタメイト側）— 販促の中心

### 4-1. 全体の流れ

```
ゲストが予約 → コインを確保（この時点では成立していない）
  → ピタメイトが承諾 → 予約成立
  → プレイ完了 → 報酬コインが付与される
  → 同時にプラットフォーム利用料が引かれる
  → 5,000コイン以上たまったら換金申請
```

**報酬コインはサービス内の支払いに充てられません**（換金専用）。

### 4-2. 手数料の段（超過累進・`host_fee_tiers`）

**月間の「予約」売上に対する超過累進**です。所得税と同じで、
**段を超えた分だけ**その段の率になります。全体が一律で切り替わるのではありません。

| 月間累計（コイン） | その段の率 |
|---|---:|
| 〜 30,000 | **20%** |
| 30,001 〜 100,000 | **17%** |
| 100,001 〜 300,000 | **14%** |
| 300,001 〜 | **12%** |

- 月の区切りは **日本時間（Asia/Tokyo）の暦月**
- 数える対象は **実際にホストに渡った額**（`host_monthly_ticket_gmv()`）。
  額面ではありません（`0122`）——全額返金で終わった予約や無断欠席の没収は**入りません**。
  詳しくは 4-5
- 出典：`fee_rates()` の `bookingTiers`

### 4-3. 指名リピート割引

> ⚠️ **基準は 3ポイントです。** 一律ではありません——下限10%に当たる段だけ
> 削られて 2pt になります。**この2つを取り違えると計算がまるごとずれます。**

| 項目 | 値 |
|---|---|
| 条件 | **同じゲストと過去に実際に遊んだ予約がある**（2回目以降）。申し込んだだけ・全額返金で終わった予約は数えません（`0122`）。詳しくは 4-5 |
| **引き下げ幅（基準）** | **3ポイント**（`c_repeat_discount = 0.03`） |
| 下限 | **10%**（`c_rate_floor = 0.10`）。これを下回りません |

割引は固定値ではなく、**下限で頭打ちになる**形です。

```
割引 = min(3pt, その予約の限界率 − 10%)
```

| その予約の限界率 | 計算 | 実際の割引 | 適用後 |
|---:|---|---:|---:|
| 20% | min(3, 10) | **3pt** | 17% |
| 17% | min(3, 7) | **3pt** | 14% |
| 14% | min(3, 4) | **3pt** | 11% |
| 13%（14%と12%をまたぐ位置） | min(3, 3) | **3pt** | 10% |
| **12%** | min(3, **2**) | **2pt** ← 削られる | 10% |

**12%の段は月間30,000コインではなく300,000コイン超**なので、
通常は 3pt が効きます。2pt になるのは最上位の段だけです。

> 出典：`_booking_fee_coins()`（`0102`）の `c_repeat_discount = 0.03`。
> `fee_rates()` は `repeatDiscountPoints: 3` を返します。
> 事業計画書・税理士レビューも 3pt 前提です（実効率18%の根拠）。


### 4-5. 「数える予約」と「数えない予約」（`0122`）

月間GMV（段の判定）とリピート判定は、**どちらも同じ1つの基準**で決まります。

> **プラットフォームがその予約を「役務の対価」として扱ったか。**
> 実装上は `platform_fees`（`kind='booking'`）の明細があるかどうかです。

| 予約の終わり方 | 段（GMV）に数える | リピートに数える |
|---|:---:|:---:|
| 完了した | ○（渡った額） | ○ |
| 遊んだあとにキャンセルした（`0102`） | ○（渡った額） | ○ |
| 全額返金で終わった（受取 0） | × | × |
| 無断欠席でゲストの支払いが没収された | × | × |

最後の2行が要点です。**額面ではなく「実際に渡った額」**なので、
返してもらった予約で段を上げたりリピート資格を作ったりはできません。
没収はホストに渡りますが、**遊んでいない**（機会損失の補償であって
役務の対価ではない）ので、こちらも数えません。

> 販促物で「○回目から割引」と書くときは、**「一緒に遊んだ回数」**と表現してください。
> 「予約した回数」は実装と食い違います。

### 4-4. 1件あたりの手数料の計算式（`_booking_fee_coins()`）

```
GMV前  = その月に**実際に発生した報酬**の合計（この予約を除く／4-5）
GMV後  = GMV前 + この予約の額

基礎手数料 = 累進(GMV後) − 累進(GMV前)      ← この予約分の「限界」手数料
実効率    = 基礎手数料 ÷ この予約の額

リピートなら:
  割引 = min(0.03, max(0, 実効率 − 0.10)) × この予約の額

手数料 = min( max(0, round(基礎手数料 − 割引)), この予約の額 )
報酬   = この予約の額 − 手数料
```

> **重要**：手数料は**実際に付与された額**にかかります（`0103`）。
> 一部返還つきの保留解除では予約額より小さくなり、全額返還なら手数料は 0 です。
> **受け取っていないものからは引きません**（規約 第8条の2第2項）。

### 4-5. 報酬額の計算例

**前提：時給1,000コイン（30分500コイン）**

#### 例A — 始めたばかり・新規ゲスト・60分

| | |
|---|---:|
| 予約額 | 1,000 コイン |
| 月間累計（この予約を含めて） | 1,000 → 20% の段 |
| 手数料 | 200 コイン（20%） |
| **報酬** | **800 コイン** |

#### 例B — 同じ条件でリピートゲスト

| | |
|---|---:|
| 予約額 | 1,000 コイン |
| 実効率 | 20% |
| リピート割引 | 3pt（20% → 17%） |
| 手数料 | 170 コイン |
| **報酬** | **830 コイン** |

#### 例C — 段をまたぐ月（月間累計 29,000コインの状態で 3,000コインの予約）

| | |
|---|---:|
| GMV前 | 29,000 |
| GMV後 | 32,000 |
| 20%の段の分 | 1,000コイン × 20% = 200 |
| 17%の段の分 | 2,000コイン × 17% = 340 |
| 基礎手数料 | 540 コイン（実効率 **18.0%**） |
| **報酬（新規）** | **2,460 コイン** |
| リピートなら | 540 − 90 = 450 → **報酬 2,550 コイン**（実効15%） |

#### 例D — 下限に当たる場合（月間累計が 300,000 超・12%の段・リピート）

| | |
|---|---:|
| 実効率 | 12% |
| リピート割引 | min(3pt, 12% − 10% = 2pt) = **2pt**（※基準は3pt。ここは下限に当たって削られた例） |
| 適用率 | **10%**（下限） |
| 1,000コインの予約なら手数料 | 100 コイン → **報酬 900 コイン** |

> ⚠️ **10% に届くのは「月間累計 300,000コイン超」かつ「リピート」のときだけ**です。
> 始めたばかりの人が最初に見る率は **20%** です。

### 4-6. 月間シミュレーション（手数料の推移）

**時給1,000コイン・すべて新規ゲスト・60分の予約を積み上げた場合**

|---:|---:|---:|---:|---:|
| 10,000 | 20% | 2,000 | 8,000 | 20.00% |
| 30,000 | 20% | 6,000 | 24,000 | 20.00% |
| 50,000 | 17% | 9,400 | 40,600 | 18.80% |
| 100,000 | 17% | 17,900 | 82,100 | 17.90% |
| 200,000 | 14% | 31,900 | 168,100 | 15.95% |
| 300,000 | 14% | 45,900 | 254,100 | 15.30% |

## 5. 換金（ピタメイト → 銀行振込）

> 🔴 **現在、実際の振込は停止中です（弁護士確認待ち）。**
> 申請は溜められますが、振込は実行されません。
> **販促でこれを伏せないでください**——「遊ぶ時間が報酬コインに」とだけ書いて
> 振込時期に触れないのは、景品表示法5条2号（有利誤認）のおそれがあります。

| 項目 | 値 |
|---|---|
| レート | **1コイン = 1円** |
| 事務手数料 | **300コイン（= ¥300）一律** |
| 最低申請額 | **5,000コイン** |
| 振込額 | 申請コイン − 300 |
| 必要条件 | 本人確認済み ＋ 銀行口座登録済み |
| 退会時の最終換金 | 最低額の適用なし。**全額をまとめて**申請 |

**計算例**

| 申請 | 手数料 | 振込額 |
|---:|---:|---:|
| 5,000 | 300 | **¥4,700** |
| 10,000 | 300 | **¥9,700** |
| 50,000 | 300 | **¥49,700** |

新規ユーザーは登録から **30日間**、換金が保留されます（`new_user_payout_hold_days`）。

## 8. 安全設計（訴求に使えるもの）

| 項目 | 内容 |
|---|---|
| 本人確認 | 掲載するピタメイトは**必須**。ゲスト側は任意（本人確認済みのみ受付も設定可） |
| 承認制 | 誘いを受ける範囲を設定できる |
| ブロック | **予約もトークも不可**になる（`0121` で実装を揃えた） |
| 非表示 | ブロックより軽い出口。**相手には何も起きず、伝わらない** |
| 通報 | カテゴリ別。運営が確認し、投稿の取り下げは理由つきで通知 |
| みまもり | 同意にもとづく監視。撤回すると投稿・メッセージが止まる |
| ランキング | **プレイ実績・評価・信頼性**で決まる。**課金額・投げ銭額は一切含まない** |

**信頼指標の表示ルール**（少ない母数の数値は出さない）

| 指標 | 出す条件 |
|---|---|
| マナースコア | レビュー **3件以上** |
| ドタキャン率 | 約束 **3件以上** |

届かないうちは「—」を表示します。

## 9. ⚠️ 販促コピーの禁止事項（生成プロンプトに必ず入れる）

### 9-1. 使ってはいけない表現

| ❌ 使わない | ✅ 言い換え |
|---|---|
| 会える／出会える／出会い／**出会い系**（**否定の形でも**） | 一緒に遊べる／ゲーム仲間が見つかる／**本来の目的以外の利用はできません** |
| 彼女・彼氏／恋活・婚活 | ゲーム仲間・フレンド |
| かわいい子と／女の子と（性的訴求） | 気の合う仲間と／上手い人と |
| 稼げる／即金（過度な煽り） | 遊ぶ時間が報酬コインに（控えめに） |
| 貢ぐ／投げ銭で1位／ランキング課金 | プレイ実績で評価 |
| デート／2人きり／会いに行く | 一緒にプレイ／オンラインで遊ぶ |
| **ホスト／キャスト／メンバー** | **ピタメイト**（アプリ内の呼称に統一） |
| 確定していない特典の予告（「先行特典」「お得情報」） | 確定した内容だけを、確定してから告知する |
| **「手数料最大10%」**（下限を上限のように書く） | **「20%から。下がって最小10%」** |
| 「手数料10%」を単独で出す | 到達条件（月間300,000コイン超＋リピート）を併記 |
| ギフトの率に触れず「手数料10%」 | **「予約の」手数料**と明示（ギフトは一律35%） |

### 9-2. なぜ「ホスト」と呼ばないか（恒久的な制約）

語感の問題ではありません。**役務を接客業と見られない一線**
（所得税法204条1項6号の非該当、出会い系サイト規制法上の非該当性）は、
**呼称・演出・プロフィール様式まで含めて**維持することが前提になっています。
弁護士が「税務と法務で同じ一線を守れ」と明示した箇所です。

### 9-3. その他

- **比較広告はしない**（根拠資料の保管が必要で、相手の料率変更に追随できない）
- **18歳未満は利用できません。** 年齢を誤認させる表現も不可
- 性別を訴求軸にしない（「女性ピタメイト募集」の形にしない）。
  「女性も安心して遊べる」は**ゲスト向けの安全訴求**として使うもので、
  **募集の条件にはしません**

## 10. 販促ツールを作るときの実装メモ

### 10-1. 手数料計算の疑似コード

```js
const TIERS = [
  { upto: 30000,  rate: 0.20 },
  { upto: 100000, rate: 0.17 },
  { upto: 300000, rate: 0.14 },
  { upto: null,   rate: 0.12 },
]
const REPEAT_DISCOUNT = 0.03   // 基準3pt。下限10%に当たる段だけ実際は2ptになる
const RATE_FLOOR = 0.10

/** 月間累計 gmv に対する累進手数料の総額 */
function progressiveFee(gmv) {
  let fee = 0, prev = 0
  for (const t of TIERS) {
    if (gmv <= prev) break
    const upper = t.upto ?? gmv
    fee += (Math.min(gmv, upper) - prev) * t.rate
    prev = upper
  }
  return fee
}

/** 1件の予約の手数料と報酬 */
function bookingFee({ gmvBefore, coins, isRepeat }) {
  const base = progressiveFee(gmvBefore + coins) - progressiveFee(gmvBefore)
  const rate = base / coins
  const discount = isRepeat
    ? Math.min(REPEAT_DISCOUNT, Math.max(0, rate - RATE_FLOOR)) * coins
    : 0
  const fee = Math.min(Math.max(0, Math.round(base - discount)), coins)
  return { fee, earned: coins - fee, effectiveRate: fee / coins }
}
```

**検算**（この4つが合えば実装は正しいはずです）

| 入力 | 期待する手数料 |
|---|---:|
| `gmvBefore=0, coins=1000, isRepeat=false` | 200 |
| `gmvBefore=0, coins=1000, isRepeat=true` | 170 |
| `gmvBefore=29000, coins=3000, isRepeat=false` | 540 |
| `gmvBefore=300000, coins=1000, isRepeat=true` | 100 |

```
→ { bookingTiers, giftPercent, floorPercent, repeatDiscountPoints,

```
