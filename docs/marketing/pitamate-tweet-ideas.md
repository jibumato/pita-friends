# ピタメイト向け PRツイート案

`sns-launch-kit.md` の ⑤・⑤-2 を、**訴求の軸ごとに広げたもの**です。
順番と媒体は [`pr-targeting-plan.md`](pr-targeting-plan.md)（結論：**ピタメイトが先・X が主戦場**）。

**末尾の数字はXの重み（上限280）。**実測値です。

## 信号の見かた

| | 意味 |
|---|---|
| 🟢 | **いま出せます。**お金が入ることを言っていません |
| 🟡 | **換金（振込）の弁護士OKが出るまで出しません。** または「○月から振込を開始します」と時期を明示できるようになってから |

> ⚠️ **`docs/legal/open-legal-matters.md` の恒久的制約：換金は弁護士OKまで実行しない。**
> 報酬コインは貯まりますが、**振り込まれません。**
> それを伏せて報酬を訴求するのは、**いちばん失いたくない相手を、いちばん強く裏切ります**
> （景品表示法5条2号のおそれもあります）。詳しくは `pr-targeting-plan.md` §2。

**いちばん強い軸だと思います。**「時間を売る」と聞いて身構える人が
まず知りたいのは、**どこまで自分に決定権があるか**です。

**B-1（258/280）**

```

・遊べる時間帯を自分で登録
・誰から誘いを受けるかも自分で設定

ノルマもシフトも待機義務もありません。
やりたい時に、やりたい相手と。
#ピタフレ #ゲーム仲間募集
```

**B-2（218/280）**

```
ピタフレのピタメイトに、ノルマはありません。

シフトもありません。待機義務もありません。
「今週はやらない」も自由です。

遊べる時間帯を登録して、来た誘いを受けるかどうか決めるだけ🎮
そういう設計にしています。
#ピタフレ
```

> **ノルマ・シフト・待機義務がないのは、設計上の事実**です

### 軸⑬ 供給側が主役（Metafy の型）

Metafy は**コーチを主役の顧客に置いた**ことで伸びました（海外編 §4）。
「募集します」ではなく**「あなたが主役の設計になっています」**という向きで言います。

**N-3（246/280）**

```
ピタフレは、ピタメイトが主役のつくりです。

・料金も時間も受ける相手も、決めるのは自分
・ノルマもシフトも待機義務もありません
・ランキングはプレイ実績・マナー・信頼性で決まります

「選ばれるのを待つ」より「自分の看板で立つ」に近いです🎮
#ピタフレ
```

**N-4 自分の看板で告知できる（211/280）**

```

フォロワーさんに自分で案内してOK。
予約・トーク・決済はぜんぶアプリ内で完結します。
#ピタフレ #ゲーム仲間募集
```

> **N-4 が Metafy の核です。**フォロワーを持つピタメイトが自分の媒体で
> 自分のプロフィールを案内すると、それがそのままピタフレの集客になります。
> **広告費のかからない唯一の拡がり方**です。
>
> ⚠️ **ステマ規制（景表法・2023年10月〜）との線引き：**
> ピタメイトが**自分の役務を自分で宣伝する**のは対価をもらった宣伝ではないので
> 問題ありません。**当社が対価（手数料の優遇・コイン等）を渡して
> 「ピタフレを良く言う投稿」をしてもらう**と、その瞬間に「PR」表示が要ります。
> **今はやりません。**やるときは表示の運用を決めてから（海外編 §4）。

## 使い方

**週3〜4本。同じ軸を、角度を変えて何度も出します。**
一度言ったから伝わった、ということは起きません。

**1週間の組み方の例（🟢だけで回す場合）**

| | 内容 |
|---|---|
| 月 | 軸①（決められる）B-1 |
| 水 | 軸②（断れる）C-1 |
| 金 | 軸④（上手くなくていい）E-2 |
| 日 | 軸⑨（問いかけ）J-1 |

翌週は同じ枠に B-2 / C-2 / E-1 / K-1 を入れる、という回し方です。
3週目は N-1 / N-6 / N-5 / N-3 と、海外の型（軸⑫〜⑮）で同じ枠を回せます。
