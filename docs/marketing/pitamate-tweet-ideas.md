# ピタメイト向け PRツイート案

`sns-launch-kit.md` の ⑤・⑤-2 を、**訴求の軸ごとに広げたもの**です。
順番と媒体は [`pr-targeting-plan.md`](pr-targeting-plan.md)（結論：**ピタメイトが先・X が主戦場**）。

**末尾の数字はXの重み（上限280）。**実測値です。

---

## 信号の見かた

| | 意味 |
|---|---|
| 🟢 | **いま出せます。**お金が入ることを言っていません |
| 🟡 | **換金（振込）の弁護士OKが出るまで出しません。** または「○月から振込を開始します」と時期を明示できるようになってから |

> ⚠️ **`docs/legal/open-legal-matters.md` の恒久的制約：換金は弁護士OKまで実行しない。**
> 報酬コインは貯まりますが、**振り込まれません。**
> それを伏せて報酬を訴求するのは、**いちばん失いたくない相手を、いちばん強く裏切ります**
> （景品表示法5条2号のおそれもあります）。詳しくは `pr-targeting-plan.md` §2。

## 軸① 自分で決められる 🟢

**いちばん強い軸だと思います。**「時間を売る」と聞いて身構える人が
まず知りたいのは、**どこまで自分に決定権があるか**です。

**B-1（258/280）**

```
＼ ピタメイト募集 ／
ピタフレは、あなたが決めることがとても多いです🎮

・料金は30分ごとに自分で設定
・遊べる時間帯を自分で登録
・誰から誘いを受けるかも自分で設定

ノルマもシフトも待機義務もありません。
やりたい時に、やりたい相手と。
#ピタフレ #ゲーム仲間募集
```

**B-2（218/280）**

```
ピタフレのピタメイトに、ノルマはありません。

シフトもありません。待機義務もありません。
「今週はやらない」も自由です。

遊べる時間帯を登録して、来た誘いを受けるかどうか決めるだけ🎮
そういう設計にしています。
#ピタフレ
```

> **ノルマ・シフト・待機義務がないのは、設計上の事実**です
> （規約 第8条6項。税務上の整理の前提にもなっています）。
> **言えば言うほど良い**種類の事実です。

## 軸② 断れる・安全（供給側の視点） 🟢

**④は「ゲストの安全」を言っています。ここは「ピタメイトの安全」です。**
同じ機能でも、向きが違えば別の投稿になります。

**C-1（258/280）**

```
ピタメイトになると、いちばん多く使う機能はたぶん「断る」です。

・誘いは全部、承認してから始まります
・誰から誘いを受けるかを、自分で決められます
・断った理由を説明する必要はありません

断れることが、続けられることだと思っています🎮
#ピタフレ #ゲーム仲間募集
```

**C-2（228/280）**

```
ピタメイトをやるとき、いちばん怖いのは
「連絡先を渡すこと」だと思います。

ピタフレは、やり取りがぜんぶアプリ内で完結します。
LINEもDiscordのIDも、渡す必要はありません🎮
（一緒に遊ぶときの通話は、好きなものを使ってOK）
#ピタフレ
```

**C-3（228/280）**

```
ピタメイト側の安全も、同じだけ作りました🛡️

・ワンタップで通報＆ブロック、相手に通知されません
・不適切なメッセージは送信前に検知します
・本人確認は、誘う側にも必要です

嫌な思いをしない、が前提です。
#ピタフレ #ゲーム仲間募集
```

> ⚠️ **C-2 の括弧は落とさないでください。** これが無いと
> 「通話もできないのか」と読まれます。**外部のボイスチャット併用は禁止していません**
> （禁止しているのは金銭のやり取りを外へ持ち出すこと）。

## 🟡 換金の弁護士OKが出てから出すもの

**下の4本は、お金が入ることを前提にしています。**
振込が止まっているあいだは出しません。

**M-1 手数料を全部出す（243/280）**

```
手数料の話、全部書きます。

・予約：20%スタート。月の累計が増えると 17→14→12%
・同じゲストの2回目以降はさらに3pt引き（下限10%）
・ありがとうギフト：一律35%
・振込：申請1件につき300コイン、最低5,000コインから

隠すところは無いです🎮
#ピタフレ
```

**M-2 続けるほど報われる（245/280）**

```
ピタフレは「同じ人と続けて遊ぶ」ほど、
ピタメイトの手数料が下がります。

一見さんを数こなすより、
「また来週も」と言ってもらえるほうが報われる。

そういう順番にしたかったので、
リピートは3pt引き（下限10%）にしています🎮
#ピタフレ #ゲーム仲間募集
```

**M-3 振込の条件（211/280）**

```
振込のはなし💰

・毎週日曜締め、翌週金曜払い
・最低5,000コインから
・手数料は申請1件につき300コイン
・振込先は本人名義の口座のみ

月末締め翌月払いだと最大60日待たせることになるので、
週次にしています🎮
#ピタフレ
```

**M-4 やることは変わらない（238/280）**

```
「遊ぶ時間を売る」と言うと身構えるかもしれませんが、
やることは普段と変わりません。

得意なゲームを、誰かと一緒に遊ぶだけ🎮
違うのは、その時間に値段をつけられることだけです。

料金は30分ごとに自分で決められます。
#ピタフレ #ゲーム仲間募集
```

> **M-1 と M-3 の数字は、変えたら投稿も直してください。**
> 出典は `0091`（料率）・`0102`（リピート割）・`0063`（振込の条件）と
> `docs/payouts-bank-operations.md` です。

## 使い方

**週3〜4本。同じ軸を、角度を変えて何度も出します。**
一度言ったから伝わった、ということは起きません。

**1週間の組み方の例（🟢だけで回す場合）**

| | 内容 |
|---|---|
| 月 | 軸①（決められる）B-1 |
| 水 | 軸②（断れる）C-1 |
| 金 | 軸④（上手くなくていい）E-2 |
| 日 | 軸⑨（問いかけ）J-1 |

翌週は同じ枠に B-2 / C-2 / E-1 / K-1 を入れる、という回し方です。
