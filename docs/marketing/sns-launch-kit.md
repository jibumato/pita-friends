## 6. NG表現（コンプラ上ぜったい使わない）

本来の目的以外の利用を想起させる表現は、立ち位置を崩すため厳禁です。**否定の形でも使いません**（§6-3）。

| ❌ 使わない | ✅ 言い換え |
|---|---|
| **会える／出会える／出会い／出会い系**（否定の形でも） | 一緒に遊べる／ゲーム仲間が見つかる／**本来の目的以外の利用はできません** |
| 彼女・彼氏／恋活・婚活 | ゲーム仲間・フレンド |
| かわいい子と／女の子と（性的訴求） | 気の合う仲間と／上手い人と |
| 稼げる（過度な煽り）／即金 | 遊ぶ時間が報酬コインに（控えめに） |
| 貢ぐ／投げ銭で1位／ランキング課金 | 応援ではなく「プレイ実績で評価」 |
| デート／2人きり／会いに行く | 一緒にプレイ／オンラインで遊ぶ |
| **ホスト／キャスト／メンバー（接客業を想起させる呼称）** | **ピタメイト**（アプリ内の呼称に統一） |
| **「先行特典」「お得情報」など、確定していない特典の予告** | 予告しない。**確定した内容だけを、確定してから告知する** |
| **「手数料最大10%」など、下限を上限のように書く** | **「手数料は20%から。下がって最小10%」**（§6-2） |
| **「手数料10%」だけを単独で出す** | 到達条件（月間累計300,000コイン超＋リピート）を併記する |
| ギフトの手数料に触れずに「手数料10%」と書く | **「予約の」手数料と明示する**（ギフトは一律35%） |

- 「稼げる」系は**過度に煽らない**（換金は弁護士確認まで開始しない方針とも整合）。
- ⚠️ **「ホスト」と呼ばない。** アプリ内の呼称は「ピタメイト」です。
  これは語感の問題ではなく、**恒久的な制約**です——役務を接客業と見られない一線
  （源泉徴収の所得税法204条1項6号の非該当と、出会い系サイト規制法上の非該当性）は
  **呼称・演出・プロフィール様式まで含めて**維持することが前提になっています。
  弁護士が「税務と法務で同じ一線を守れ」と明示した箇所で、
  **PRで「ホスト募集」と書くのは、その一線に自分から触りにいく**ことになります。
- ⚠️ **確定していない特典を予告しない。** 購入時の上乗せコインは
  `0083` で**廃止済み**で、現在「お得」と言える材料はありません。
  景品表示法5条2号（有利誤認）に触れるおそれがあるうえ、
  期待して待った人を裏切ります。
- 投げ銭・課金額でのランキングは存在しません。ランキング＝**プレイ実績・評価・信頼性**であることを明示。
- 未成年の利用はできません（18歳未満不可）。年齢を誤認させる表現もNG。

## 6-2. 手数料の書き方（⚠️ 数字を間違えやすいところ）

**「手数料最大10%」は事実と逆です。最大は20%で、10%は下限です。**

実装上の数字は次のとおりです（**ここが唯一の出典**。告知に数字を書くときは
必ずこの表と突き合わせてください）。

| 出典 | 中身 |
|---|---|
| `host_fee_tiers`（`0033`、変更は `0091` の運営コンソール経由） | 月間の**予約**売上に対する超過累進：〜30,000コイン **20%** ／ 〜100,000 **17%** ／ 〜300,000 **14%** ／ 300,000超 **12%** |
| `_booking_fee_coins()`（`0102`） | `c_repeat_discount = 0.03`（同一ゲストのリピートは3pt引き）／ `c_rate_floor = 0.10`（**下限10%**） |
| `gift_fee_rates`（`0091`） | ありがとうギフトは**一律35%**。予約とは別の率です |

つまり **10%に届くのは「月間累計が300,000コイン超（12%の段）」かつ
「同じゲストからの2回目以降」の場合だけ**です。始めたばかりの人が最初に
見る率は **20%** です。

### 書いてよい形

- ✅ **「予約の手数料は20%から。遊ぶほど下がって、最小10%」**
- ✅ **「同じ人と続けて遊ぶほど手数料が下がります（3pt引き・下限10%）」**
- ✅ 段階を全部並べる（20% → 17% → 14% → 12%）
- ❌ 「最大10%」「手数料10%〜」（10%は最小であって、そこから始まりません）
- ❌ 他社との比較（**比較広告は根拠資料の保管が要ります**。相手方の料率が
  変わった時点で追随できないので、当面やりません）

> **下限を上限のように書くと、景品表示法5条2号（有利誤認）**に当たります。
> 「実際には20%取られる」という一点で、説明のしようがありません。
> 数字を伏せる必要はまったくなくて、**「下がっていく」という構造そのものが
> 訴求になります**（⑤-2）。
>
> ⚠️ **料率を運営コンソールから変更したら、この節と⑤-2も直してください。**
> `0091` は将来の料率を予約できるので、**告知の数字だけが古くなる**ことが起こります。

## 6-3. 「出会い系」という語は、否定の形でも使わない

**告知・プロフィール・キャプション・画像、どこにも書きません。**
言い換えは **「本来の目的以外の利用はできません」** に統一します。

**なぜ否定でもだめか。** 「出会い系ではありません」と書くと、
**その語と一緒にブランド名が並びます。** 読む側に残るのは否定ではなく
**並んだこと自体**で、検索でも「ピタフレ 出会い系」が結び付きます。
自分から結び付けにいく必要はありません。

**「本来の目的」が何かは、同じ投稿の中に必ず書いてあります。**
概要説明（②-2）はどれも「一緒にゲームを遊ぶ時間を予約するアプリ」と
先に言ってから、この一文が来る形になっています。**単独で使わないでください。**
前提が無いところに置くと、何が禁止なのか分かりません。

### ⚠️ 一方で、次の場所からは**消していません**

| 場所 | 理由 |
|---|---|
| **利用規約 第2条2項・第9条1項** | 「異性交際・恋愛・出会いを目的とするサービスではない」と規約で**明示的に定めていること自体**が、出会い系サイト規制法の非該当性を支えています。弁護士確認済みの条文です |
| **プライバシーポリシー／みまもり同意画面** | みまもりの**利用目的の特定**（個人情報保護法17条）です。「本来の目的以外」まで抽象化すると、目的を特定したことになりません |
| **通報カテゴリ（`dating_solicitation`）** | 通報する人が自分の状況を選び、運営が仕分けるためのものです。抽象化すると選べず、仕分けもできません |
| **`contentGuard.ts` の検知ルール** | 内部の判定です。表示される語ではありません |
| **`docs/legal/` の各文書** | 法的な当てはめの記述です。法令名と論点名は正確に書く必要があります |

> **区別は「宣伝か、ルールか」です。**
> **宣伝では言わない。ルールでは明確に書く。** 表記ゆれではなく、意図的に分けています。

## 7. 画像

**画像の作り方は [`image-prompts.md`](image-prompts.md) にあります。**
そのまま使えるプロンプト（英語）とサイズ表、確認の手順を入れてあります。

⚠️ **画像も同じ一線を守る対象です。** 文面だけ気をつけても、

とくに**1人の女性キャラを大きく主役に置く構図**は避けてください。

正しく描けず、それらしい形の別の字になります。**絵だけ作って、文字は
Canva 等で後から載せます。**
