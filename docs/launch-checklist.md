## A. ホスティング(Cloudflare で稼働中)

> 当初はVercelを想定していましたが、**実際にはCloudflareで運用しています**
> (2026-07-26に実態へ合わせて更新)。`wrangler.jsonc` の `assets` 設定による
> 静的配信で、Workerスクリプトは使っていません。

1. ✅ Cloudflare へのデプロイ(`main` にマージすると反映される)
   - ✅ **【2026-08-03】配信を GitHub Actions に移した。**Cloudflare 側の自動ビルドが
     無言で止まり、6コミットが配信されないまま気づけなかったため。手順は
     [`deploy.md`](deploy.md)。APIトークンの登録・Cloudflare 側の Git 接続の解除まで
     完了し、`main` への push で自動配信されることを確認済み
2. ✅ 環境変数 `VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY` の設定
   ※この2つは公開されても安全な値です(service_roleキーは**絶対に**入れない)
3. ✅ **独自ドメインの取得・接続**: `https://pitafure.com`(2026-07-26)
   - 特商法表記の販売URL・index.html の OGP も差し替え済み
4. ✅ **`www.pitafure.com` の扱いを決める**(2026-07-27)
   - `www` のプロキシ済みDNSレコードを追加し、リダイレクトルール(テンプレート
     「WWWからルートにリダイレクト」)で apex(`pitafure.com`)へ301。動作確認済み
5. ✅ スマホ実機で「ホーム画面に追加」(PWA)が動くか確認(2026-07-27)
   - iPhone実機でオフライン起動時に「Response served by service worker has
     redirections」で失敗する不具合を発見・修正済み(`public/sw.js`、cache v6)
6. ✅ **ホーム画面への追加をアプリ内で案内する**(2026-07-29、`src/lib/install.ts`)
   - iOSには追加ボタンが存在せず、Safariの共有シートからしか入れられない。
     案内がないと誰も気づかないので、環境ごとに文面を変えて出すようにした
   - **X・Instagram・LINE のアプリ内ブラウザからは追加できない。** 流入の主力が
     SNSなのでここが一番多く、共有シートの手順を出すと押しても項目がなくて詰む。
     この場合だけ「外のブラウザで開き直す」案内(URLコピー / Androidはintentで
     Chrome起動)に切り替える
   - 出す場所は3つ: お気に入り登録の直後(0054の枠空き通知が届く相手ができた瞬間) /
     マイページのカード / 設定の行。閉じた回数で14日→60日→打ち切り
   - 実機での確認項目: **iOS Safari で追加 → アイコンから起動したときに
     案内が消えること**(`display-mode` と `navigator.standalone` で判定)
   - ⚠️ Androidで既に追加済みの人がタブで開くと案内が一度出る
     (`beforeinstallprompt` が飛ばないため)。閉じれば止まる
7. ◑ **Web Push**(2026-07-29 実装、0064)。**鍵の設定が残っています。**
   手順は [web-push-setup.md](web-push-setup.md)。要点だけ:
   - VAPID鍵を作る → Cloudflare に `VITE_VAPID_PUBLIC_KEY`、Supabase の
     Secrets に `VAPID_PRIVATE_KEY` / `VAPID_SUBJECT` / `PUSH_CRON_SECRET`
   - `supabase functions deploy push-send --no-verify-jwt`
   - pg_cron から1分おきに push-send を叩く / 1日1回 `prune_push()`
   - **`VITE_VAPID_PUBLIC_KEY` が空のあいだは通知の導線が一切出ません**
     (壊れたボタンは出ないので、未設定のまま公開しても事故らない)
   - ⚠️ **秘密鍵はリポジトリに絶対に入れない。** 漏れると第三者が
     ピタフレを名乗って利用者にプッシュを送れます
   - ⚠️ **公開鍵は一度公開したら変えない。** 変えると既存の購読が全部
     無効になり、利用者に再登録してもらう手立てがありません
   - 実機確認: iPhoneをホーム画面に追加 → ⭐を付けて説明シート → 許可 →
     **アプリを閉じた状態で**予約リクエストが届くこと →
     `message_received` でロック画面に本文が出ないこと
