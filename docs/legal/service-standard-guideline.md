## 1. このガイドラインが定めるもの

利用規約第9条第4項の「**提供された内容が合意した内容と著しく異なる場合**」について、当社が判断するときの枠組みを定めます。

> **以下に掲げるのは典型例の例示であり、これに限られません。** 個別の事情は、
> 双方から聴取した事実と客観的な資料に基づいて総合的に考慮します（第4項）。

〔※この留保を**冒頭に置く**のは2026-08-05の弁護士回答（論点D(a)3）によります。「例示列挙＋総合考慮の構造にすれば縛りは限定できます。……**限定列挙にしないこと**が要点です。」末尾にもありましたが、**読み始める前に効かせる**必要があります。〕

## 2. 前提 — 結果は保証しません

本サービスでピタメイトが提供するのは「**インターネットを通じてゲームを一緒に遊ぶ時間**」です。成果物のある請負ではなく、**合意した態様で誠実に履行する債務**です。

したがって、「楽しくなかった」「期待した雰囲気と違った」「相手が上手ではなかった」といった**主観的な満足の不足は、本項の対象になりません**。

判定するのは、**合意された提供態様の中核的要素が満たされたかどうか**です。

## 3. 中核的要素 — 4つ

「著しく異なる」とは、次の中核的要素の**全部または重要部分の不履行が、客観的な資料で確認できる場合**をいいます。

| | 要素 | 判定の仕方 |
|---|---|---|
| ① | **時間** | 開始・終了・実プレイ時間。システムの記録で客観的に判定します。量的な欠落は、**時間に応じた一部返還（按分）を原則**とします。回線不調が双方に責めのない場合も同様に按分します。**全部の返還は、まったく提供されなかった場合（無断欠席・開始に至らなかった場合）に限ります** |
| ② | **本人性** | 登録者本人によるプレイか。**なりすまし・別人の操作は常に該当**し、全額を返還します。無断欠席も同様です（第9条第1項・第3項） |
| ③ | **対象** | 合意したゲーム・モードか。ただし**事後に双方が合意して変更した場合は該当しません**（合意の変更）。トークの履歴で確認します |
| ④ | **態様** | 募集文・プロフィール・事前のやり取りで**明示的に約束された事項**（「ボイスチャットで会話しながら」「初心者に教えながら」等）。**約束の存否**で切り分けます |
| ⑤ | **共同プレイの実体** | ④の約束の有無にかかわらず、**社会通念上「一緒に遊んだ」と評価できない態様**（下記）。この要素だけは、何も約束していなくても該当し得ます |

### ④について — 「終始無言だった」の扱い

プロフィール・募集文・事前のトークにおいて**会話を伴うプレイが明示的に掲げられていた場合**に、客観的な資料（ボイスチャットの使用記録、トークの履歴等）から**実質的な交流が皆無であったと認められるとき**に限り、該当し得ます。

単に会話が弾まなかった、期待した雰囲気と違った、プレイが上手でなかったといった**主観的な満足の不足は該当しません**。

〔※この「約束ベース」の切り分けは、結果を保証しない役務の債務不履行判断と同じ構造で、**ピタメイトに誠実な履行を求めつつ品質保証には踏み込まない**線です。恒久的な制約（相殺・控除を「品質への不満」型に及ぼさない）とも整合します。〕

### ⑤について — 何も約束していなくても該当する下限

**「無言であること」自体は該当しません。** 黙々と協力プレイをするのは、この役務の正常な形のひとつです。

該当するのは、**チャット・ゲーム内の合図（ピン等）・ゲーム内の行動を含めて一切の応答がなく、共同でプレイした実体を欠く**と認められる場合に限ります。典型的には、参加はしているが**操作をせずに放置されていた**場合です。

〔※⑤は**2026-08-05の弁護士回答（論点D(b)）により追加**しました。従前は④の「約束ベース」しか置いておらず、**何も約束していないピタメイトが最初から最後まで放置していた場合を拾えません**でした。

> 「『無言』自体は該当せず（黙々と協力プレイするスタイルは正常な役務です）、**チャット・ピン・ゲーム内行動を含む一切の応答がなく、共同プレイの実体を欠く場合**に限り該当。逆にいえば『盛り上がらなかった』『下手だった』等の主観的品質への不満は該当しない、と**非該当例を明記する**ことが、恒久的制約（相殺を品質不満型に及ぼさない）の防波堤にもなる。」

**下限を1つ置くことと、品質を保証することは別**です。⑤は「一緒に遊ぶ時間」という役務の最低限の輪郭にすぎず、面白さや上達を約束するものではありません。〕

## 4. 判断の留保

1. **本ガイドラインに掲げる事項は、典型例の例示であり、これに限られません。** これに該当しない場合でも、個別の事情により判断することがあります。
2. 最終的には、**双方から聴取した事実と客観的な資料に基づき、当社が合理的に判断**します。

〔※この2つの留保により、事前公表による自己拘束は「**公表した基準から不合理に逸脱しない**」という望ましい水準に収まります（弁護士）。逆に基準なき個別判断を積み重ねるほうが、後日まとめて恣意的運用として攻撃される危険が大きいとのことです。〕
