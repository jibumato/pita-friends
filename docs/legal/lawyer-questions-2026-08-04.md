# 第1部 サービスの仕組み

## 1-1. 何をするサービスか

**オンラインゲームを一緒に遊ぶ相手を探し、時間を予約して、一緒に遊ぶ**だけの
サービスです。すべてインターネット上で完結します。

| 呼称 | 役割 |
|---|---|
| **ゲスト** | 一緒に遊ぶ相手を探して予約し、対価を支払う側 |
| **ピタメイト** | 一緒に遊ぶ時間を提供し、対価を受け取る側 |

〔※「ピタメイト」は当方の造語です。「ホスト」「キャスト」等の**特定の業態を
想起させる一般名詞を意図的に避けています**（第2部2-3）。〕

**役務の内容は「インターネットを通じてゲームを一緒に遊ぶ時間」に限られます。**
規約第5条第7号で、本サービスを通じた**対面での面会を伴う役務および飲食の提供を
伴う役務**を提供・申出・要求することを禁止しています。

## 1-2. お金の流れ

サービス内通貨「コイン」を介します。**1コイン＝1円**です。

```
  ①購入              ②予約              ③完了確定           ④換金
ゲスト ──→ 当方 ──→（コインを消費）──→ ピタメイトの報酬 ──→ 銀行振込
      21,000円     当方が預かる状態     （利用料を差引後）   （手数料300円控除）
```

**① 購入** … 決済代行会社（Stripe）を通じてクレジットカード等で購入。
明細は2行で、コインの代金と、**あんしんサポート料（5%）**です。後者は通報対応・
本人確認・トラブル時の個別相談などの**安全確保の役務の対価**として規約第7条の3に
役務を列挙しています（**保険や補償ではありません**）。

**② 予約** … 予約するとその場でコインが消費されますが、**この時点では
ピタメイトの報酬になりません。** 当方が預かった状態で保持します。単価は
**ピタメイトが自ら設定**し、当方が定めるのは上限・下限のみ（50〜2,000コイン/時）です。

**③ 完了確定** … ゲストが確定するか、終了予定時刻から72時間の経過で自動確定。
確定した時点で預かっていたコインが**ピタメイトの報酬コイン**になります。ここで
**プラットフォーム利用料**（予約12〜20%の段階制／ギフト一律35%）を差し引きます。

**④ 換金** … 報酬コインは**本人名義の銀行口座への振込**で金銭に換えられます
（最低5,000コイン・事務手数料300コイン・毎週日曜締め翌週金曜払い）。
**ゲストが購入したコインは換金できません**（第7条3項）。換金できるのは
**役務の対価として得た報酬コインだけ**です。

**補足: ありがとうギフト** … プレイ後にゲストが任意で贈る追加の謝礼です。
**完了した予約がある相手にのみ**贈ることができ、上限（1回5万・1日5万・30日20万円
相当）、購入直後24時間の送信禁止、相互送金の禁止、受領から7日間の換金保留を
設けています。

# 第2部 すでに整理がついている前提

いずれも過去3回のご確認で維持できるとされたものです。**ご異論があれば
それが最も重要な情報**ですが、本書の主眼は第3部です。

| # | 整理 |
|---|---|
| 2-1 | **収納代行** … 予約対価の収納は「既存債務の弁済受領（受領権限授与＋債務消滅構成・第8条4項）」で説明する。当方は取引の当事者ではない |
| 2-2 | **資金決済法の適用除外** … コインの有効期限を**発行日から6か月未満**（取得日から起算して6か月を経過する日の前日まで）に設定し、同法第4条の適用除外に該当させる |
| 2-3 | **出会い系規制法の非該当** … 面識のない異性との交際を目的とする役務ではない。対面・飲食を伴う役務を規約で禁止し、呼称・演出も接客業を想起させないものにしている |
| 2-4 | **源泉徴収義務の非該当** … 所得税法204条1項6号（ホステス等）に当たらない。上記2-3と**同じ一線**を守ることで両方が成立する |

### 前回いただいた「恒久的な制約」（当方で遵守しています）

| 制約 | 外すと崩れるもの |
|---|---|
| **報酬コインをサービス内の支払いに使えるようにしない** | 資金決済法の整理が根元から揺らぐ |
| **あんしんサポート料を損失填補の原資と説明しない** | 自ら保険構成を招く |
| **相殺・控除を「品質への不満」型にまで及ぼさない** | 片面的なリスク転嫁条項となり許容性が急落 |
| **ギフトの相手方限定・上限・保留・相互送金禁止を緩めない** | 為替取引該当性の議論を招く |

# 論点B. ありがとうギフトの為替取引該当性

> 予約対価の収納は「既存債務の弁済受領（受領権限授与＋債務消滅構成）」で
> 説明できますが、**ギフトには既存債務がありません。既存債務のない資金の移動を
> 媒介する行為は、為替取引（資金移動業）該当性の議論を招く典型です。**
> 完了予約の相手方限定・上限・保留・相互送金禁止という現行の設計は正しい方向です。

**「正しい方向」とまでは言っていただきましたが、該当しないという結論は
いただいていません。**「分析メモを整備すること」が宿題として残っています。

## 当方の現在の設計

| 制限 | 内容 |
|---|---|
| 相手方の限定 | **完了した予約がある相手にのみ**贈れる（無関係な相手への送金を防ぐ） |
| 金額の上限 | 1回5万・1日5万・30日20万円相当 |
| 時間の制限 | **購入直後24時間は送信禁止** |
| 相互送金 | **禁止**（A→BとB→Aの双方向を検知して遮断） |
| 換金の保留 | 受領から**7日間**は換金不可 |
| 監視 | 同一IP・同一決済カードでの送受信を検知し、**換金前の目視対象**として記録 |

利用料は**一律35%**（予約の12〜20%より高く設定）としています。

# 論点C. 報酬コインが前払式支払手段に当たらないことの説明

## 背景

コインには2種類あります。

| | 取得の経路 | 使途 | 換金 |
|---|---|---|---|
| **購入コイン** | ゲストが購入 | 予約・ギフト | **不可** |
| **報酬コイン** | 役務の対価として取得 | **換金のみ**（サービス内の支払いには使えない） | 可 |

購入コインは前払式支払手段（自家型）として扱い、有効期限を6か月未満にすることで
資金決済法の適用除外に乗せています。

**報酬コインについては、「サービス内の支払いに使えない＝前払式支払手段の定義に
当たらない」**という整理をしており、前回「この構成を崩さないこと」を
恒久的な制約として指示されています。

ただし、**その説明を2点補強するように**とされたまま、当方でメモを整備できていません。

## お伺いしたいこと

- **(a)** 「サービス内の支払いに使えない」ことをもって前払式支払手段に
  当たらないとする整理は、**どのような理由づけで説明するのが適切**でしょうか
- **(b)** この整理を維持するために、**規約または実装で追加すべき手当て**は
  ありますか。現在は実装上も報酬コインを支払いに充当できない作りにしています
- **(c)** 報酬コインを**将来サービス内の支払いに使えるようにしたい**という
  要望が出た場合（利用者から出ることが予想されます）、**何が崩れるのか**を
  当方が説明できる形にしておきたく、その要点をご教示ください
