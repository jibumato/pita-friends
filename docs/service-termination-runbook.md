# サービス終了の手順書（規約 第13条2〜5項）

> **これは「使わないことを願う文書」です。** ただし、書いていない手順は実行できません。
> 第13条2〜5項は 2026-07-31 に**当社が自ら約束した内容**なので、
> 履行できる状態にしておかないと、そのまま債務不履行になります。

## なぜ規約に書いたのか

弁護士（総評3・論点8(d)）の指摘：

> **適用除外により資金決済法20条の払戻義務がないからこそ**、規約で自主的に手当てして
> おかないと、消費者契約法10条・不当利得の争点として残る。対価を受けて役務を提供しない
> まま終了する場面の不返金は、議論を免れない。

コインの有効期限を6か月未満にして適用除外を採ったのは事業判断です。その裏返しとして、
**終了時に「払い戻さない」と言い切れない**——というのがこの条項の位置づけです。

## 約束していること（第13条）

| 項 | 約束 |
|---|---|
| 2項 | 終了の**90日前まで**に告知する |
| 3項 | 終了時点で**有効期限内のコインは、残高に相当する額を金銭で返金**する（期限切れは対象外） |
| 4項 | 報酬コインは、**最低申請額5,000コインと換金手数料300コインの定めにかかわらず**換金する |
| 5項 | 3項・4項の**方法と期限を、2項の告知で明らかにする** |

## 手順

### T-100日: 判断と準備（告知の前）

1. **終了日を決める。** 告知から終了まで90日以上を確保する（2項）
2. 返金・換金の原資を確認する

```sql
-- 返金・換金にいくら要るか（1コイン=1円）
select
  (select coalesce(sum(remaining), 0) from public.coin_lots
    where kind = 'paid' and remaining > 0 and expires_at > now())    as "返金が要る有償コイン",
  (select coalesce(sum(earned_balance), 0) from public.coin_wallets) as "換金が要る報酬コイン",
  (select coalesce(sum(amount_yen), 0) from public.cash_refunds
    where status = 'pending')                                        as "未払いの返金(円)";
```

> ⚠️ **分別管理口座の残高がこれを下回っていたら、終了の判断より先に資金の手当てが要ります。**
> 分別管理規程の目的そのものなので、ここで足りない状態は規程違反です。

3. **新規の購入を止める。** 告知の前に止めると混乱するので、告知と同時にする

```sql
update public.coin_packs set active = false;
```

### T-90日: 告知（第13条2項・5項）

告知に**必ず含める**もの（5項が「方法および期限を明らかにする」と約束している）：

- 終了日
- **有効期限内のコインの返金**: 方法（振込先の登録）と、申請の期限
- **報酬コインの換金**: 最低申請額と手数料を適用しないこと、申請の期限
- 問い合わせ窓口

告知の場所：アプリ内のお知らせ（`notifications` の全員配信）、トップページ、登録メール。
**アプリ内だけにしない。** 終了間際はログインしない利用者が増えます。

### T-90日〜終了日: 受付

- 予約の新規作成を止める（終了日をまたぐ予約を作らせない）
- **すでに成立した予約は履行またはキャンセルまで見届ける**（退会の第6条の2第2項と同じ考え方）
- 換金の申請を受け付ける。**5,000コイン未満でも、手数料300コインも取らない**（4項）

> 換金の最低額と手数料は `request_bank_payout` が判定しています。終了時は
> **この2つを外した migration を当てる**か、運営が `payouts` に直接起票します。
> どちらにするかは、そのときの残件数で決めてください（数十件なら後者が速い）。

### 終了日以降: 返金の実行（第13条3項）

1. 有効期限内のコインを確定させる

```sql
-- 返金の対象（有償のみ。無償コインは対価を受け取っていないので0円）
select l.user_id, p.nickname, sum(l.remaining)::int as coins, sum(l.remaining)::int as yen
from public.coin_lots l
left join public.profiles p on p.id = l.user_id
where l.kind = 'paid' and l.remaining > 0 and l.expires_at > now()
group by l.user_id, p.nickname
order by yen desc;
```

2. 振込先を集める（本人確認済みの口座があればそれを使う。無ければ請求フォーム）
3. 振り込む
4. **`cash_refunds` に記録して支払済みにする。** 既存の返金台帳（0085）をそのまま使えば、
   会計仕訳（J19・J20）にも自動で乗ります

### 会計・記録

- **`ledger_export` の外部バックアップを、終了後も保存する。** 法定の保存期間
  （電子帳簿保存法・7年）は終了で消えません
- `accounting_journal()` と `accounting_journal_check()` を最終期でも実行し、
  前受金・預り金が**0に落ちる**ことを確認する
- 終了の記録（告知日・終了日・返金と換金の件数と総額）を1つの文書に残す
