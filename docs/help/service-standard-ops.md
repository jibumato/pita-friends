# 「約束と違った」の申出への対応（運営メモ）

作成日: 2026-08-04

**この文書はアプリに出しません。** 利用者向けの事例集は
[`service-standard-examples.md`](service-standard-examples.md)、
判断の枠組み（規約の一部）は

### 事例を追加するとき

**この文書の更新は規約変更ではありません。** 既存の枠組み（ガイドラインの中核的要素4つ）の解釈を具体化するものとして扱います。したがって第15条の周知手続は不要です。

ただし、**枠組みそのものを変えるとき**（例：中核的要素を増やす、按分の原則を変える）は、ガイドラインの改訂＝規約変更になります。第15条の手続が必要です。

### 判断したら記録すること

| 項目 | なぜ |
|---|---|
| 申出の日時と、確定日からの経過日数 | 14日の期限内か |
| 双方から聴取した内容 | 「片方の話だけで決めた」と言われないため |
| どの中核的要素で判断したか | 枠組みに沿った運用であることの裏づけ |
| 客観的資料（トーク履歴・プレイ記録の該当箇所） | 後から再現できるように |
| 結論と、その理由 | 同種の事案で結論がぶれないように |

**この記録の蓄積そのものが、事業者側の最も有効な防御資料**です（弁護士・論点D(a)）。基準を公表しておきながら記録が無いと、「公表しただけで運用していない」という評価になります。

### 返還の原資 — どこから出すか（2026-08-06 追加）

**ここを決めておかないと、原因不明の按分がピタメイトの報酬を削る形になります。**

| 場面 | 原資 | 根拠 |
|---|---|---|
| **完了の確定前**（大半はここ） | 当社が預かっている分（規約 第9条4の2第1号） | まだ誰のものでもない |
| **確定後で、ピタメイトに帰責がある** | ピタメイトの未払報酬から控除（同2号） | 債務不履行の帰結 |
| **確定後で、原因が分からない** | **当社が負担**（ピタメイトの報酬から控除しない） | 下記 |

> **どちらの帰責も立証できないときに、ピタメイトの報酬から控除しない。**
> 2026-08-05の弁護士回答（論点D(b)）:
>
> 「原因不明 → 按分返還とし、その原資は**第9条4の2第1号（確定前の預かり分）から
> 充てる**（どちらの帰責も立証できない場合にピタメイトの報酬から控除しない、
> という運用ルールを内規に）。」
>
> **確定前に処理すれば自動的にこの形になります。** 第9条6項末尾により、
> 通報・申出があれば自動確定は止まるので、**申出を受けたらまず確定を止める**こと。
> 確定してしまってから原因不明の按分を行うと、原資が無く、
> ピタメイトの報酬に手を付けるしかなくなります。

**運営コンソールの「保留」タブから確定を止められます**（`admin_held_bookings`）。
