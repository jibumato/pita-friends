## はじめに — 「楽しくなかった」は対象になりません

ピタメイトが提供するのは「**一緒にゲームを遊ぶ時間**」です。ゲームの結果や、楽しさそのものをお約束するものではありません。

- 「思ったより楽しくなかった」
- 「相手があまり上手ではなかった」
- 「会話が弾まなかった」
- 「期待していた雰囲気と違った」

こうした**感じ方の問題は、返還の対象になりません**。プレイの前に相手のプロフィールやレビューをよくご覧いただき、気になることは事前にトークで確認してください。

一方で、**約束された内容そのものが果たされなかった場合**は、ご相談ください。以下でその線引きを説明します。

## 見るのは4つ

| | 何を見るか |
|---|---|
| **時間** | 予定した時間、一緒に遊べましたか |
| **本人** | プロフィールの本人がプレイしましたか |
| **対象** | 約束したゲームを遊びましたか |
| **約束** | 募集文やプロフィールに書かれていたことは守られましたか |

## ケース別

### 全額をお返しするもの

| 起きたこと | 理由 |
|---|---|
| **ピタメイトが現れなかった（無断欠席）** | 時間がまったく提供されていません。システムの記録で判定でき、ご相談も不要です（自動で返還されます） |
| **別の人がプレイしていた（なりすまし）** | 本人によるプレイは、このサービスの前提です。相手を選んで申し込む意味が失われます |
| **開始できないまま終了時刻を迎えた** | ピタメイト側の事情による場合。回線不調も含みます |

### 時間に応じてお返しするもの（按分）

| 起きたこと | 扱い |
|---|---|
| **回線不調で、予定の半分しか一緒に遊べなかった** | 遊べなかった時間の分をお返しします |
| **ピタメイトの都合で途中で終了した** | 同上 |

> **どちらが悪いとも言えない場合も、時間で按分します。** 回線の不調は、どちらのせいとも決められないことがほとんどです。「誰が悪いか」を突き止めてから決めるのではなく、**提供された時間の分だけお支払いいただく**という考え方にしています。
>
> 〔※法的には危険負担の割り切り。事前に開示しておくことで、事後の恣意的判断という評価を避ける（弁護士・論点D(b)）。〕

### 場合によるもの — 「約束」があったかで決まります

| 起きたこと | 該当する場合 | 該当しない場合 |
|---|---|---|
| **終始ほとんど会話がなかった** | プロフィール・募集文・事前のトークで「**ボイスチャットで会話しながら**」等が明示されていて、記録から実質的な交流が皆無だったと確認できるとき | 会話について何も約束していなかったとき。または、会話はあったが弾まなかったとき |
| **教えてもらえなかった** | 「**初心者に教えます**」等が明示されていたのに、まったく応じなかったとき | 特に約束していなかったとき |
| **約束と違うゲームを遊んだ** | ゲストが同意していないのに変更されたとき | **プレイ中に双方が合意して変更したとき**（トークの履歴で確認します） |

**「約束があったか」で切り分けます。** ピタメイトの側も、募集文に書いていないことまで求められては困りますし、書いたことは守っていただく必要があります。

### 対象にならないもの

- ゲームに負けた／思うような結果にならなかった
- 相手のプレイが上手ではなかった
- 性格や話し方が合わなかった
- 自分の回線・機材の不調で遊べなかった
- **プレイ完了の確定から14日を過ぎてからのご相談**（利用規約第9条第4項）

## ご相談の流れ

1. **プレイ完了の確定から14日以内**に、お問い合わせ窓口へご連絡ください
2. 何が起きたか、いつ・どの予約かをお知らせください
3. 当社が**双方から事情をうかがいます**。片方の話だけで決めることはありません
4. トークの履歴・プレイの記録などの客観的な資料とあわせて確認します
5. 結果と、その理由をお伝えします

**確認の内容と判断の理由は記録して保存します。**

- 最終的には、双方からうかがった事実と客観的な資料に基づいて、当社が判断します
