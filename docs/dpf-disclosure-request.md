# 販売業者情報の開示請求への対応手順（取引DPF法5条）

作成日: 2026-08-04

2026-08-04の弁護士回答（第1の3⑦）により作成。

> 「反復継続して有償役務を提供するピタメイトは、**取引デジタルプラットフォーム消費者保護法上の『販売業者等』に該当し得ます**。その場合、当社は同法の取引DPF提供者として、**苦情処理体制等の努力義務（3条）**と、**消費者からの販売業者情報の開示請求制度（5条）**への対応が問題になります。」

---

## この手順が要る理由

**ゲストが、ピタメイトに損害賠償を請求したいのに相手の氏名も住所も知らない**、という場面のためのものです。当社は「当事者ではない」立場ですが、**当事者でないからこそ、当事者にたどり着く手段を用意しておく義務**が生じます。

規約 第8条第7項で、ピタメイトから事前の同意を得ています。**同意が無いまま開示すると、こちらが個人情報保護法違反になります。**

## 開示の要件（同法5条）

次を**すべて**満たすときに、開示します。1つでも欠けたら開示しません。

| # | 要件 | 確認の仕方 |
|---|---|---|
| ① | 請求者が、その取引の**消費者**であること | 予約またはギフトの記録に、請求者本人がゲストとして存在するか |
| ② | 販売業者等に対する**損害賠償請求権その他の権利の行使**のために必要であること | 請求書に請求の内容が書かれているか。「知りたいだけ」は不可 |
| ③ | 当該権利の行使について**正当な理由**があること | 役務が提供されなかった、著しく異なった等の具体的な事実があるか |
| ④ | 請求が**不正の目的**によるものでないこと | 嫌がらせ・つきまとい・名誉毀損の疑いがないか |

**開示するのは、その取引の相手方であるピタメイトの情報だけです。** 他の取引・他のユーザーの情報は含めません。

## 手順

1. **請求を受け付ける**（問い合わせ窓口）。書面またはメールで、次を書いてもらう
   - 請求者の氏名・連絡先
   - 対象の取引（予約日時・相手のニックネーム）
   - **権利行使の内容と、その理由となる事実**
2. **上の4要件を確認する。** 判断に迷ったら、開示せずに弁護士に相談する
3. **対象のピタメイトへ通知する**（開示する旨と、その理由）
   - ⚠️ **法令上必須ではありませんが、必ず行ってください。**黙って開示すると、こちらとピタメイトの信頼関係が壊れます
   - 反論の機会を与え、④（不正の目的）の判断材料にする
4. **開示する**。開示した内容と、判断の理由を記録する
5. 開示しない場合は、**理由を付して請求者に回答する**

## 記録

開示の可否にかかわらず、次を残します。**この記録自体が、体制を備えていたことの証拠になります。**

- 請求の内容と受付日
- 4要件それぞれについての判断と、その根拠
- ピタメイトへの通知の日時と、その反応
- 開示した情報の範囲（または開示しなかった理由）
- 対応した者と対応日

## ⚠️ やってはいけないこと

| | 理由 |
|---|---|
| **要件を確認せずに開示する** | 個人情報保護法27条違反。規約の同意は「法令に基づく請求があったとき」の同意であって、無条件の同意ではありません |
| **請求者に「当事者ではないので関知しない」と返す** | 3条の努力義務に反します。取引の当事者でないことと、開示に応じないことは別の話です |
| **ピタメイトに黙って開示する** | 法令上は可能ですが、信頼関係を壊します。3の通知は運用として必ず行ってください |
| **他の取引の情報を含めて開示する** | 開示の範囲は請求に係る取引に限られます |
